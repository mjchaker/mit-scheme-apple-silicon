# Runtime library map, command line and R7RS support

Where things live in `src/runtime`, what the launcher accepts, and how
R7RS libraries are wired in. Names of procedures and files come from
the source; line numbers are omitted because they drift.

## 1. Command line

Microcode options must come first; the runtime processes the rest.

### Microcode options (`src/microcode/option.c`)

| Option | Meaning |
| --- | --- |
| `--library PATH`, `--prepend-library DIR` | Library path (default from `MITSCHEME_LIBRARY_PATH`) |
| `--band FILE` | Band to load; default `all.com`, falling back to `runtime.com`. Conflicts with `--fasl` |
| `--fasl FILE` | Cold load |
| `--heap N`, `--stack N`, `--constant N` | 1024-word blocks. Default heap 16384 blocks on 64-bit. The heap is added to the band's own size |
| `--batch-mode`, `--quiet`, `--silent` | Synonyms. Suppress banner and exit message, skip `~/.scheme.init`, suppress load messages, clear the interactive flag |
| `--emacs` | Running as an Emacs subprocess |
| `--interactive` | Force interactive mode even when stdio is not a tty |
| `--nocore`, `--macosx-application` | Apple-specific and rarely needed |
| `--option-summary`, `--help`, `--version` | Informational |

Deprecated and ignored: `--compiler`, `--edwin`, `--large`, `--utab`,
`--utabmd`.

### Runtime options (`src/runtime/command-line.scm`)

| Option | Meaning |
| --- | --- |
| `--no-init-file` | Do not load `~/.scheme.init` |
| `--load FILE...` | Load each file in the nearest REPL environment |
| `--eval EXPR...` | Read and evaluate each expression |
| `--edit` | Start Edwin |
| `--suspend-file`, `--no-suspend-file` | Suspend-file handling |
| `--args ARG...` | Append to `(command-line-arguments)`; `--` appends everything after |

Unhandled options produce a warning. A typical script invocation:

```sh
mit-scheme --batch-mode --no-init-file --load foo.scm --eval '(%exit)'
```

## 2. Subsystem map (`src/runtime`)

### Syntax and macros

`syntax form env` is the entry point (`syntax.scm`), and `eval` is
`(extended-scode-eval (syntax expression environment) environment)`
(`global.scm`). The pipeline, all under the `(runtime syntax)` packages:

- `classify-form` walks the form using `syntax-environment.scm`
  (syntactic environments, renaming), `syntax-items.scm`,
  `syntax-parser.scm` and `syntax-check.scm`.
- `syntax-constructor.scm` / `syntax-declaration.scm` build items.
- `syntax-rename.scm` renames identifiers and post-processes.
- `syntax-output.scm` emits SCode.
- MIT special forms: `mit-syntax.scm` (`define-syntax`,
  `sc-`/`rsc-`/`er-macro-transformer`), `mit-macros.scm`
  (`define-record-type`, `cond`, `do`, ...). `syntax-rules.scm` and
  `defstr.scm` (defstruct).
- Reverse direction: `unsyn.scm` (SCode to s-expression) and `pp.scm`
  (pretty printer).
- `src/sf` translates whole source files to SCode with optimization;
  see [COMPILER.md](COMPILER.md).

Tests: `test-syntax`, `test-syntax-rules`, `test-syntax-rename`.

| Low-level I/O | `primitive-io.scm`, `os-primitives.scm`, `socket.scm`, `http-client.scm` |

| Lists, vectors, misc | `list.scm`, `srfi-1.scm`, `vector.scm`, `bytevector.scm`, `bitstr.scm`, `rbtree.scm`, `wttree.scm`, `trie.scm`, `stream.scm`, `generator.scm`, `comparator.scm` |
| Records, predicates | `record.scm`, `predicate.scm`, `predicate-dispatch.scm`, `dispatch-tag.scm`, `parametric-predicate.scm`, `compound-predicate.scm` |

### Control and concurrency

- **Threads** (`thread-low.scm`, `thread.scm`, package `(runtime
  thread)`): green threads driven by the timer interrupt. `create-thread`,
  `current-thread`, `yield-current-thread`, `join-thread`,
  `exit-current-thread`, `signal-thread-event`, thread mutexes and
  `with-thread-mutex-lock`. Related: `condvar.scm`, `thread-barrier.scm`,
  `thread-queue.scm`.
- **Structured concurrency:** `task.scm`, package `(runtime task)`; see
  [CONCURRENCY.md](../CONCURRENCY.md).
- **Events** (`events.scm`): distributors such as `event:before-exit`,
  `event:after-restore` and `event:after-restart`.
- **dynamic-wind and state spaces** (`wind.scm`), continuations
  (`contin.scm`), parameters (`dynamic.scm`).
- **Condition system** (`error.scm`): `make-condition-type`,
  `access-condition`, `with-simple-restart`, `invoke-restart`,
  `bind-condition-handler`, `signal-condition`, `error`, and R7RS
  `with-exception-handler` / `raise`. `microcode-errors.scm` maps
  microcode error codes to condition types.
- **Weak references:** `weak-pair.scm` (weak lists and alists), ephemerons
  (`make-ephemeron` in `global.scm`), used by `predicate.scm` and
  `hash-table.scm`.
- **GC:** `gc.scm`, `gcdemn.scm`, `gcfinal.scm` (`make-gc-finalizer`),
  `gcnote.scm`, `gcstat.scm`.

### Environment and tooling

REPL and user interface: `rep.scm`, `usrint.scm`, `dbgcmd.scm`,
`debug.scm`, `emacs.scm`, `savres.scm` (`disk-save`). Loading and
packages: `load.scm`, `option.scm`, `optiondb.scm`, `packag.scm`,
`environment.scm`.

### FFI

`src/runtime/ffi.scm` (package `(runtime ffi)`) plus `ed-ffi.scm`.
`src/ffi` builds the `ffi` load option: `syntax.scm` (the C-declaration
syntax), `cdecls.scm`, `ctypes.scm`, `generator.scm`, `build.scm`.
Tests are in `tests/ffi`. The C plugins (`src/gdbm`, `blowfish`,
`pgsql`, `x11`) are built on it.

## 3. R7RS support

R7RS is implemented mostly inside the runtime, not in `src/libraries`.

### Machinery (`src/runtime/library-*.scm`)

- `library-parser.scm` parses `define-library` (`import`, `export`,
  `begin`, `include`, `include-ci`, `include-library-declarations`,
  `cond-expand`).
- `library-loader.scm` provides `environment`, `top-level-environment`,
  `scheme-report-environment`, `null-environment`, the REPL `import`,
  `syntax-r7rs-source` and `eval-r7rs-source`.
  `find-scheme-libraries!` scans library directories on
  `event:after-restore` and preregisters what it finds.
- `library-standard.scm` maps the standard libraries onto the global
  runtime environment via `define-standard-library`: `(scheme base)`,
  `case-lambda`, `char`, `complex`, `cxr`, `eval`, `file`, `inexact`,
  `lazy`, `load`, `process-context`, `read`, `repl`, `time`, `write`,
  `r5rs`, and SRFIs 1, 2, 6, 8, 9, 23, 27, 39, 69, 112, 115, 124, 125,
  128, 129, 131, 143, 158, 162, 219. `define-synthetic-library` derives
  `(mit legacy runtime)` from every `(runtime ...)` package's exports.
- Library file types (`load.scm`): `sld` (source), `binld`, `comld`,
  `infld`, `bcild`.
- Search path: the system `libraries/` directory and the user's
  init-file libraries directory.

### Extra libraries (`src/libraries`)

`srfi-14.sld`, `srfi-133.sld` (+ impl), `srfi-140.sld` (+ impl) and
`inline-testing.sld` (+ impl). `compile.scm` compiles every `.sld`; the
`Makefile-fragment` installs `*.comld` / `*.bcild` to
`$(AUXDIR)/libraries`. A typical library:

```scheme
(define-library (srfi 133)
  (import (scheme base) (only (mit legacy runtime) fix:+ ...))
  (export ...)
  (include "srfi-133-impl.scm"))
```

Tests: `tests/libraries/test-srfi-*`, `tests/runtime/test-library-*`
(with `test-library-data/`).
